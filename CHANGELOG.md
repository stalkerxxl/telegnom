### Added
- Initial project structure.
- Implementation of core Bot API methods.
- support Telegram Bot API v9.3
- Middleware system (Global, Group, Local).
- Webhook and Long Polling support.
- Flexible filtering system.
- GitHub Actions for CI (Tests, Lint, Security).
- MIT License and Contributing guidelines.
- Multi-language README (EN/RU).
